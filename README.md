# Project 11 — Infrastructure Changes with Branching Policy

## Objective
Implement a structured Git branching policy for infrastructure code changes.

## Tasks
- Create a Git repository.
- Maintain a stable main branch.
- Create feature branches for changes.
- Commit and push changes.
- Submit Pull Requests for review.
- Merge approved changes into main.

## Branching Strategy
- `main`: Stable and approved code.
- `feature/*`: New infrastructure changes.
- Pull Requests: Required before merging changes.

## Tools
- Git
- GitHub
- Visual Studio Code

## Deliverables
- GitHub repository
- Feature branch
- Merged Pull Request link
